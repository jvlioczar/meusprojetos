# Fonte do site meusprojetos.biblioverse.org

Os projetos, categorias e textos (português e inglês) ficam em `build.py`.

Para atualizar o site:

1. Edite `build.py`
2. Rode `python3 _fonte/build.py` (precisa do Python 3.9+ e da biblioteca Pillow)
3. Faça commit dos arquivos gerados na raiz do repositório

As pastas que começam com `_` não são publicadas pelo GitHub Pages.
